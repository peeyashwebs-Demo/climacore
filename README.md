## Quote form (Supabase)
1. Create a Supabase project and run `supabase/schema.sql` in the SQL Editor. Visitors can only insert; only you can read leads.
2. Put the project URL and publishable/anon key in `SITE` (`js/main.js`). The key is public by design; the table's permissions are what protect your data.
3. Submit a real test request and confirm the row appears in Table Editor > quote_requests.
4. Email alerts (optional): deploy `supabase/functions/notify-quote` with `--no-verify-jwt`, set its secrets (see the file header), then add a Database Webhook (INSERT on quote_requests) that calls it with an `x-webhook-secret` header.
Until step 2 is done the form says it isn't connected. If spam appears, add Cloudflare Turnstile and route inserts through an Edge Function.
Replace the text-consent placeholder with attorney-approved wording before launch. Run `python3 build.py` after editing page copy.

Newsletter: `supabase/schema.sql` also creates `newsletter_signups`. Add the sender name/postal address (CAN-SPAM) before sending any email.
